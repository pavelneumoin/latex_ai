## 1. Продуктовая модель

Сайт — **магазин материалов для учителей математики и информатики** + рабочий кабинет.

Единица продажи — **Product**:
- `lesson_kit` — комплект урока (презентация + рабочий лист + шпаргалка + ДЗ + зачёты) — основной товар;
- `worksheet` / `presentation` / `test` — отдельные элементы (продажа отдельных элементов);
- `course_bundle` — курс целиком со скидкой.

### Уровни материалов (tiers)

| Уровень | Что входит | Кому |
|---|---|---|
| **free** | Бесплатные образцы (первый урок каждого курса) | Все, без регистрации — маркетинг |
| **basic (PDF)** | Все PDF комплекта: презентация, лист, шпора, ДЗ, зачёты + ключи ответов | Учитель «печатай и веди» |
| **source (PDF + исходники)** | То же + исходники: Marp `.md` (презентация), LaTeX `.tex` (листы) — правь под себя | Продвинутый учитель, репетитор, методист |

Исходники — наша уникальная фишка: никто на рынке (Инфоурок/Мультиурок) не продаёт
редактируемые Marp/LaTeX-исходники профессиональной вёрстки.

### Ценовая политика (мягкая, старт)

Материалов пока мало → цены минимальные, цель — первые покупки и отзывы:

| Товар | PDF | PDF + исходники |
|---|---|---|
| Комплект урока | **49 ₽** | **129 ₽** |
| Отдельный элемент (лист/презентация) | **19 ₽** | **49 ₽** |
| Курс целиком (5–8 уроков) | **199 ₽** (~50 % выгоды) | **499 ₽** |
| Первый урок каждого курса | **0 ₽** | 0 ₽ (демо исходников) |

Покупка — навсегда, лежит в кабинете, повторное скачивание бесплатно.

### Подписки (по предметам!)

Сайт один, подписки раздельные — математика и информатика:

| План | Цена/мес | Цена/год (−25 %) | Что даёт |
|---|---|---|---|
| **Бесплатный** | 0 ₽ | — | Бесплатные материалы, 10 автопроверок/мес, кабинет и классы |
| **Математика** | 290 ₽ | 2 610 ₽ | Все PDF по математике + 300 проверок/мес + отчёты |
| **Информатика** | 290 ₽ | 2 610 ₽ | Все PDF по информатике + 300 проверок/мес + отчёты |
| **Всё включено** | 490 ₽ | 4 410 ₽ | Оба предмета, **исходники Marp/TeX**, безлимит проверок |

Принципы: подписка = доступ пока активна; покупка = навсегда. Подписчик может докупать
исходники поштучно со скидкой (basic-цена засчитывается). Отмена — доступ до конца периода.

## 3. Кабинет учителя (/cabinet)

Собственный layout: **desktop — левый сайдбар, mobile — нижняя таб-навигация** (5 табов).
Разделы:

1. **Обзор** — приветствие, быстрые действия, последние покупки/проверки, мини-сводка.
2. **Библиотека** — всё купленное + бесплатное сохранённое; скачивание любых активов; бейдж уровня.
3. **Классы** — CRUD классов (7А…), список учеников (быстрый ввод «списком из журнала»),
   пороги отметок на класс (5 ≥ 85 %, 4 ≥ 65 %, 3 ≥ 40 % — настраиваемые).
4. **Проверка** — мастер: выбрать материал (свой купленный с ключом) → класс → загрузить PDF/фото
   работ пачкой → обработка → таблица ученик × задания (редактируемая) → отметки по шкале →
   кнопка «Отчёт (PDF)». Пока LLM не подключён — статус `needs_review` и ручная разметка
   в той же таблице (полноценно работает уже сейчас как «полуавтомат»).
5. **Отчёты** — сформированные LaTeX-отчёты, скачать .pdf/.tex.
6. **Подписка и платежи** — статус подписок по предметам, история платежей, покупки.
7. **Настройки** — профиль, школа, предметы.

### Автопроверка (архитектура под LLM «потом»)

- У продукта: `answerKeyJson` (мастер-ключ фабрики — у нас уже есть sympy-ключи!) и
  `checkInstructions` — инструкция для нейросети под конкретный лист (как читать поля,
  формат ответов, частичные баллы).
- `CheckJob` → на каждого ученика `CheckResult{answersJson, score, pct, mark, needsReview}`.
- Пайплайн: upload → (v2: LLM vision по `checkInstructions` через `lib/llm`) → результаты.
  Сейчас: разметка вручную в таблице + автоподсчёт баллов/процентов/отметок — уже полезно.
- Статистика копится по классу и ученику независимо от способа проверки.

### Статистика → LaTeX, а не перегруженный UI

В UI — только карточки-сводки (средний %, распределение отметок, динамика).
Полная аналитика — **красивый LaTeX-документ** (фирменный стиль фабрики):
- **Отчёт по проверке**: таблица класса, гистограмма отметок, разбор по заданиям (какие провалены);
- **Отчёт по классу за период**: динамика, топ/риск-ученики, темы-провалы;
- **Отчёт по ученику**: для родителей.
Генерация: `lib/reports` → .tex → xelatex (локально есть; на сервере — контейнер) → PDF в кабинет.

## 4. Дизайн v2

Проблемы старого: безликий «shadcn-стандарт», слабый мобильный кабинет, маркетплейс выглядит как список.

Направление: **«тетрадь в клетку»** — фирменный паттерн клетки (как у наших листов),
тёплая бумажная палитра, крупная типографика Manrope:

- фон бумага `#FAF9F7`, чернила `#1C1917`;
- **математика = индиго `#4F46E5`**, **информатика = бирюза `#0D9488`** — цветовое кодирование
  всех карточек/бейджей по предмету;
- акцент (CTA, цены) — янтарь `#F59E0B`;
- клетка: CSS-паттерн 24×24 для hero/пустых состояний;
- карточка товара = «лист А4»: превью-миниатюра первой страницы, состав комплекта иконками;
- mobile-first: нижние табы кабинета, фильтры каталога в bottom-sheet, touch ≥ 44 px.

Дизайн-система выгружается в **claude.ai/design** (проект «РабочийЛист — Design System»)
через DesignSync для дальнейших итераций в Claude Design.

## 6. Наполнение (старт)

Сид из фабрики: **Вероятность 4-5 (8 уроков, готово целиком)**, **Задание 7 урок 1**,
**Векторы урок 1**, **Финансы 16 урок 1** + курс-бандл «Вероятность». Урок 1 каждого курса — free.
Копируем PDF в `frontend/storage/products/<slug>/`, превью — PNG первой страницы.
