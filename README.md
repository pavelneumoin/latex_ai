# Неумошка

**Подготовься к уроку немножко.** Библиотека готовых комплектов для учителей математики и информатики.

## Текущая версия

- Каталог с поиском и фильтрами по предмету, теме и формату материала.
- Навигатор по заданиям ЕГЭ и отдельные страницы комплектов.
- Превью презентаций, рабочих листов, домашних и проверочных работ с увеличением страниц.
- Личный кабинет, избранное и сохранение оплаченного доступа между входами.
- Один тариф раннего доступа: **499 ₽ за календарный месяц ко всем материалам**.
  Планируемая обычная цена — 1 000 ₽. Только разовая оплата: **без автосписаний и годовых тарифов**.
- Вход по почте; интеграция VK ID подготовлена, для включения нужен ID приложения VK.
- Генерация рабочих листов и другие экспериментальные инструменты находятся в разделе
  «В разработке» и закрыты для пользователей на страницах и в API.

Проект сейчас тестируется локально. Реальные платежи и VK ID ещё не подключены.
Юридические страницы отмечены как черновики для тестирования.

## Запуск

Приложение находится в `frontend/`. Инструкция по базе, переменным окружения,
импорту материалов и VK ID: **[Локальная настройка](frontend/LOCAL_SETUP.md)**.

```powershell
cd frontend
npm ci
# Подготовить .env.local и базу по инструкции выше.
npm run dev -- -H 127.0.0.1
```

Адрес после запуска: http://localhost:3010 .

## Материалы и секреты

В локальном каталоге настроены два стартовых комплекта:
«Числовая окружность» и «Кодирование изображений».
PDF, изображения превью и SQLite-база хранятся отдельно от Git.
В этом репозитории находится код сайта и скрипт импорта; сами платные материалы,
аккаунты, ключи и `.env.local` не публикуются.

## Проверка

```powershell
cd frontend
npm run typecheck
npm test
npm run build
```

Для проверки входа, тестового платежа, скачивания и истечения месяца на запущенном
локальном сервере: `node scripts/verify-local-flow.mjs`.
Команда использует только mock-платежи и удаляет созданный ею временный аккаунт.

## Перед публикацией сайта

Нужны реальная настройка VK ID, платёжного провайдера и чеков, окончательные документы
продавца, HTTPS и резервные копии. Аудит зависимостей выявил уязвимости, включая старый
Next.js 14; обновление и повторная проверка обязательны до размещения в интернете.

Код экспериментальных инструментов в `cli/` и закрытых разделах `frontend/` сохранён
для дальнейшей разработки. Материалы в `.agent/` — архив прежних технических решений;
актуальная пользовательская версия описана здесь и в `frontend/LOCAL_SETUP.md`.
