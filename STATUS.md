### Что сделано

**Продукт и данные**
- Схема v2 (миграция `20260710121841_v2_marketplace_cabinet`): `Product`, `ProductAsset`
  (уровни basic=PDF / source=Marp+LaTeX), `Purchase`, `Class`, `Student`, `CheckJob`,
  `CheckResult`, `Report`; подписки **по предметам** — `Plan.subject/tier/priceYearly`,
  `Subscription @@unique(userId, subject)`.
- Планы: Бесплатный · Математика 290 ₽ · Информатика 290 ₽ · Всё включено 490 ₽
  (год −25 %). Поштучно: элемент 19/49 ₽, комплект урока 49/129 ₽, курс 199/499 ₽.
- Сид каталога из фабрики (`prisma/seed-products.ts`, `npm run db:seed-products`):
  **12 товаров** — prob45 l1–l8 + бандл курса, kurs7-l1, kurs2-l1, kurs16-l1 (през.);
  ~130 файлов скопировано в `storage/products/`, превью — PNG первых страниц.
  Первый урок каждого курса — free (включая исходники).

**Деньги**
- `create-payment` расширен: `planId+period` (мес/год) | `productId+tier` | credits.
- Mock-касса `/billing/checkout/[id]` (форма-заглушка → webhook succeeded → активация).
- Вебхук: подписки upsert по (userId, subject), покупки c апгрейдом basic→source,
  **бандл курса открывает все его уроки**. Боевой YooKassa-адаптер не тронут —
  переключение `PAYMENTS_PROVIDER=yookassa`.

**Кабинет `/cabinet`** (сайдбар desktop / нижние 5 табов mobile)
- Обзор, Библиотека (купленное навсегда + по подписке + бесплатное, скачивание ассетов
  с проверкой прав `lib/entitlements.ts`), Классы (быстрый ввод списком из журнала,
  пороги отметок на класс), Проверка (мастер: материал → класс → загрузка PDF/фото
  пачкой → таблица баллов с автоотметками → завершение), Отчёты, Подписка/платежи.
- Автопроверка: `/api/checks/[id]/run` — при vision-LLM и ключе продукта реально
  проверяет по промпту `check_worksheet` + `Product.checkInstructions`; иначе честный
  ручной режим (баллы вводятся, проценты/отметки считаются сами).

**LaTeX-отчёты** (`lib/reports/`)
- Отчёт о проверке: шапка, сводка (средний %, качество, успеваемость), гистограмма
  отметок цветными столбиками, таблица класса, решаемость по заданиям; компиляция
  xelatex → PDF в storage (Georgia/Segoe UI, override через REPORT_FONT_*).

**Дизайн v2 «Тетрадь в клетку»** (`app/globals.css`, слой `rl2-*`)

  #0D9488, акцент янтарь; фирменный паттерн клетки 24×24; карточки-«листы» с превью.
- Новые лендинг, каталог с фильтрами-чипами, карточка товара с уровнями и «что такое
