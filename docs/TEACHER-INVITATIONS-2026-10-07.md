# Ручная выдача доступа — 7 октября 2026

## Запрос и граница публикации

Временно убрать всю информацию об оплате. Выдавать учителям логин и пароль вручную,
без обязательной почты. Для первого приглашённого учителя подготовлен бесплатный
бессрочный доступ ко всем материалам. В ответе на уточнение владелец выбрал
«Подготовить аккаунт к запуску»: сама библиотека в интернете не публикуется.
Школьная витрина `/teachers` обновляется отдельно, без цены и предложения подписки.

## Реализация

- `User.username` — необязательный уникальный логин для совместимости старых записей;
  `email` теперь необязателен. Новые аккаунты не используют выдуманную почту.
- `User.libraryAccessForever` — серверное право на все уровни всех опубликованных
  комплектов, включая будущие. Не даёт роль администратора, доступ к черновикам,
  ученическим отчётам или платным API генерации/проверки.
- Вход по логину и паролю; прежняя почта владельца остаётся допустимым логином.
  Саморегистрация и OAuth отключены. Права и активность читаются из БД при запросе.
- Кабинет показывает «Все материалы · навсегда». В каталогах нет цен.
  Старые страницы регистрации, тарифов и кассы перенаправляют на `/access`.
  API оплаты и webhook закрыты. Прежние записи покупок/подписок не удаляются.
- `scripts/issue-teacher-account.mjs` выдаёт обычный аккаунт с бессрочным доступом,
  генерирует пароль, сохраняет его только вне Git и отказывается менять существующий
  логин. В БД — bcrypt-хеш. Секреты и персональные данные не включены в коммит.

## Что осталось к запуску

Оба постоянных комплекта пока не имеют ссылки на полную папку Яндекс Диска.
Поэтому одна кнопка «Скачать комплект» остаётся неактивной с точным объяснением.
Локальный API отдельных PDF проверен; это не проверка отсутствующих комплектов
на Диске. Тест перенаправления использует временный комплект и не следует по ссылке.
Нужны реальные ссылки, проверка состава, затем отдельное согласованное размещение
библиотеки. Также остаются обновление устаревшего Next.js перед публичным запуском,
финальная политика данных, HTTPS и резервные копии. Платежи и AI-провайдер не включать.
