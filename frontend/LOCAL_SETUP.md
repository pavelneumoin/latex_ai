# Неумошка: локальная библиотека

Рабочая папка `D:/Sites/latex_ai/frontend`. Актуально на 7 октября 2026 вечером.
Публична только витрина https://neumoshka.ru/teachers . Вход библиотеки пока локальный.

## Запуск

Node 24 LTS, зависимости из lockfile. Сначала настроить `.env` и `.env.local`;
для существующей БД перед миграциями сделать согласованную SQLite backup-копию.
На этом ПК миграции уже применены; сброс или повторный seed не нужен.

```powershell
npm run db:migrate:deploy
npm run db:generate
npm run build
$env:PORT='3015'
$env:HOSTNAME='127.0.0.1'
$env:NEXTAUTH_URL='http://localhost:3015'
$env:NEXT_PUBLIC_SITE_URL='http://localhost:3015'
npm start
```

Открыть http://localhost:3015 . Для разработки `npm run dev -- -H 127.0.0.1`, порт
3010. Не запускать dev и build одновременно: они используют одну `.next`.
`start-standalone.mjs` сохраняет правильный путь к БД и хранилищу превью.
Cookies привязаны к адресу — для входа не смешивать localhost и 127.0.0.1.

## Аккаунты

Новые аккаунты создаёт только владелец. Вход — логин/пароль, без обязательной почты.
Старый вход администратора по email сохранён. Данные владельца находятся в закрытом
файле «Неумошка — администратор библиотеки.txt» на рабочем столе. Управление
комплектами: `/admin/catalog`. Обычные учителя не получают эту роль.

Чтобы **выдать бессрочный доступ ко всем нынешним и будущим комплектам**:

```powershell
node scripts/issue-teacher-account.mjs teacher.login "Имя Фамилия" D:/Sites/school-private/teacher-accounts
```

Команда генерирует пароль и сохраняет TXT/JSON только вне репозитория. Повторная
выдача существующего логина завершается без изменений. Хеш пароля и бессрочное
право сохраняются в локальной БД. Для переноса к запуску нужна сама БД с аккаунтами,
а не только Git. Не заменять действующую БД старой/тестовой копией.

Саморегистрация, OAuth, платёжные страницы и платёжные API временно отключены.
Изменить этот режим можно только отдельным проверенным выпуском. Исторические
покупки/подписки сохранены. Приглашение не открывает генератор и AI-проверку.

## Материалы и витрина

Два комплекта: «Числовая окружность» и «Кодирование изображений», всего 12 PDF.
Оригиналы пользователя не изменены. Каталог и разрешённые превью открыты;
скачивание проверяет права аккаунта. В карточке одна кнопка на полный комплект
Яндекс Диска. Пока ссылки не переданы, кнопка помечена «Ссылка готовится».
Старый защищённый API отдельных PDF сохранён для совместимости и проверки.

Для экспорта публичных описаний и оптимизированных превью в актуальную школу:

```powershell
node scripts/export-school-catalog.mjs ../../school-ege-shared
```

Экспорт не переносит цены, аккаунты, PDF и закрытые ссылки. Публикация школы —
отдельная операция по её AGENTS.md и общей блокировке. Старый `school-ege` не
использовать для публикации поверх работы другого ПК.

## Проверки

```powershell
npm test
npm run typecheck
npm run build
node scripts/verify-teacher-invitation.mjs D:/private/issued-account.json
node scripts/verify-catalog-admin.mjs
```

Последние две команды требуют локальный сервер 3015. Первая проверяет реальные PDF
выданного аккаунта и временными данными — ограничения; вторая — редактор/роли.
Тестовые записи удаляются. Настоящих платежей и загрузки архивов с Диска нет.
Прежний `verify-local-flow.mjs` относится к отключённой платёжной модели;
для текущего режима его не запускать. Подробности: `../docs/TEACHER-INVITATIONS-2026-10-07.md`.

## Перед публичным запуском

Нужны ссылки на полные комплекты и проверка их содержимого, актуализация старого
Next.js 14 и зависимостей, финальные документы с реальными контактами, HTTPS,
перенос подготовленной библиотеки и резервные копии. Вход библиотеки нельзя
подменять школьными аккаунтами. Реальные платежи и платные API сейчас не подключать.
